# Verified financial reviews

Each company has an independently authored JSON snapshot and a matching `.evidence.md` numerical transcription with primary-source URLs and page/table locators. Different agents may own different company files. Do not edit shared rendering code, generated files, or another agent's records.

Use audited full-year primary company/exchange disclosures, including restated audited figures in a prospectus where appropriate. Prefer the latest accessible annual period; explicitly identify older periods rather than inventing current figures. Verify the annual column, units, reporting scope and earnings definition. A prospectus does not establish exchange admission.

Use the same snapshot schema as the other files here (and the 11 originals still in `dist/financial-data.js`). Segment rows must use the same disclosed revenue and earnings basis. Explain intersegment sales, unallocated costs and discontinued operations. Otherwise show clearly labelled whole-company/group totals. Never infer brand profit from sales shares or turn rounded margins into profit amounts. Keep losses signed. For banks, use `revenueLabel: "Total income"` and an `incomeDefinition` explaining the measure, rather than describing bank income as product sales. Separate group PAT from profit attributable to owners.

The parent reviewer integrates the files with `node scripts/build-financial-reviews.cjs`, validates evidence and reconciliation, checks browser layouts and publishes. Original snapshots are being migrated from `dist/financial-data.js` into this folder (six so far: reliance-industries, infosys, tcs, titan-company, eternal, hindustan-unilever); once migrated, an id must be removed from `dist/financial-data.js` so it exists in one place only, and it is maintained like any other file. Snapshots still in `dist/financial-data.js` remain unchanged until migrated. When a snapshot field is corrected, record 'corrected <date>' and what changed in the evidence file header. All financial figures and interpretations must stay in the final learning section of each company page.
